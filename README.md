## 🎯 Wie benutzt man die Plattform?

### 🌍 Sprache wechseln
1. Oben rechts auf die Flaggen klicken:
   - 🇩🇪 = Deutsch
   - 🇬🇧 = English
   - 🇬🇪 = Georgian
2. Die komplette Seite wird übersetzt!
3. Wird automatisch gespeichert

### 🌙 Dark Mode aktivieren
1. Klicke auf das Mond-Icon 🌙 oben rechts
2. Perfekt fürs Lernen im Dunkeln
3. Spart Akku auf dem Handy
4. Wird automatisch gespeichert

### 📱 Auf dem Handy
1. Hamburger-Menü (☰) öffnen
2. Alle Funktionen wie auf Desktop
3. Touch-optimiert
4. Schnell & flüssig

### 📚 Vokabeln lernen
1. Scrolle zum **Vokabeln**-Bereich
2. Klicke auf 🔊 Audio-Buttons um Wörter zu hören
3. Lese die Beispielsätze
4. Nutze die Übersetzungen (English + Georgian)

### 🎴 Flashcards nutzen
1. Scrolle zum **Flashcards**-Bereich
2. Klicke auf die Karte zum Umdrehen
3. "Kann ich" → Karte als bekannt markieren
4. "Noch üben" → Weiter üben
5. Sieh deinen Fortschritt in der Progress Bar

### 🎤 Aussprache üben mit Voice Recording
1. Scrolle zur **Aussprache üben**-Sektion
2. Klicke "Anhören" um das Wort zu hören
3. Klicke "Aufnahme starten" (Mikrofon erlauben!)
4. Sprich das Wort laut und deutlich
5. Klicke "Aufnahme stoppen"
6. Höre deine Aufnahme an
7. Vergleiche mit dem Original

### ❤️ Eigene Audio-Dateien hochladen
1. Scrolle zu **"Persönliche Audio-Hilfe"**
2. Klicke "Dateien auswählen" ODER ziehe Dateien rein
3. Wähle Audio-Dateien (MP3, WAV, OGG)
4. Die Dateien werden angezeigt
5. Sie kann deine Stimme beim Lernen hören!

**💡 Tipp für dich:**
- Nimm dich auf, wie du Wörter vorsprichst
- Lade die Audio-Dateien hoch
- Sie hört deine Stimme und lernt besser!

### ✍️ Übungen machen
1. Scrolle zum **Übungen**-Bereich
2. **Artikel-Quiz**: Wähle den richtigen Artikel
3. **Lückentext**: Klicke auf die Lücken und tippe
4. **Multiple Choice**: Klicke auf die richtige Antwort
5. Sammle Punkte! 🌟

## ⌨️ Tastenkombinationen

- **ESC**: Zurück nach oben scrollen
- **S**: Aktuelles Quiz-Wort vorlesen
- **Enter**: Lückentext-Antworten prüfen (wenn Cursor in Lücke)
- **← (Links)**: Vorherige Flashcard (wenn auf Flashcard-Sektion)
- **→ (Rechts)**: Nächste Flashcard (wenn auf Flashcard-Sektion)
- **Leertaste**: Flashcard umdrehen (wenn auf Flashcard-Sektion)

## 🐛 Fehlerbehebung

### Audio funktioniert nicht?
- Moderne Browser nutzen (Chrome/Edge empfohlen)
- Ton nicht stummgeschaltet?
- Nochmal auf Audio-Button klicken

### Voice Recording funktioniert nicht?
- Mikrofon-Zugriff erlauben
- Überprüfe Browser-Einstellungen
- HTTPS-Verbindung nötig (funktioniert auf Netlify!)

### Fortschritt wird nicht gespeichert?
- Cookies/LocalStorage aktiviert?
- Nicht im privaten Modus?
- Browser-Cache nicht leeren

### Dark Mode geht nicht?
- JavaScript aktiviert?
- Seite neu laden
- Auf Mond-Icon 🌙 klicken

### Mobile Menu öffnet nicht?
- Auf Hamburger-Icon (☰) klicken
- JavaScript aktiviert?
- Browser aktualisieren
